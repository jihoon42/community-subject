커뮤니티 과제

카뎃이 만든 과제를 카뎃이 평가하고, 그 기록은 카뎃이 가진다. 과제 본문, 테스트, 평가 기록은 모두 Git 저장소의 평문 파일이며 관리자도 서버도 없다. 이 색인은 그 저장소에서 명령 하나로 누구나 다시 만들 수 있다.

원칙 셋

  1. 과제는 Git에. 과제 하나는 저장소 하나다. 프런트매터가 붙은 SUBJECT.md와 테스트가 전부이고, 버전은 태그로 매긴다. 누구나 포크해 고친다.
  2. 기록은 서명으로. 기계 평가의 결과도 사람 평가의 결과도 JSON 한 파일이고, 평가자가 자기 SSH 키로 서명한다(ssh-keygen -Y sign). 검증에는 공개키 한 줄이면 된다.
  3. 색인은 누구나 다시 만든다. 이 사이트는 저장소의 파일을 읽어 생성한 정적 HTML이다. 생성할 때 모든 기록의 서명을 다시 검증한다. 같은 저장소에서 같은 명령을 돌리면 같은 사이트가 나온다.

다시 만들기

git clone <이 저장소> community-subject
cd community-subject
make site

Go와 OpenSSH(8.0 이상)만 있으면 된다. 결과는 site/public/에 쓰이고, make serve로 미리 볼 수 있다.
